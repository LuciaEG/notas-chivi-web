# :books: Notas Chivi - Sitio Web

Proyecto realizado para la materia <strong>Programación IV</strong>.

Este sitio web fue desarrollado como trabajo práctico académico con el objetivo de crear un sitio web de baja complejidad utilizando HTML, CSS y JavaScript, incluyendo navegación entre páginas, menú desplegable, formulario funcional y galería de imágenes.

El proyecto está inspirado en el emprendimiento real de encuadernación artesanal de mi mamá: <strong>Notas Chivi</strong> :two_hearts:

## :pencil2: Descripción del proyecto

Notas Chivi es un sitio web pensado para representar la identidad visual y artesanal del emprendimiento.
Se muestran productos reales y diferentes secciones informativas sobre el trabajo de encuadernación.

El sitio cuenta con:

* Página principal (Home)
* Galería de imágenes
* Sección "Sobre mí"
* Formulario de contacto
* Menú desplegable dentro del botón de Inicio
* Footer compartido en todas las páginas
* Enlaces reales a redes sociales (Instagram y TikTok)

Todas las fotografías utilizadas fueron tomadas por mí para el emprendimiento.
